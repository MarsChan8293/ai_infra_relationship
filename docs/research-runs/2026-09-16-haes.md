## Evidence discipline learned from this run

The first four actions expose an important distinction for the planner: `project -> person` coverage is not the same as `project -> maintainer` coverage. A contributor, issue author, or recent commit author must not satisfy a maintainer action unless governance, CODEOWNERS/MAINTAINERS, stable project role, or equivalent primary evidence supports that role.

A future planner revision should therefore make relation-role coverage semantic rather than counting any neighboring person as satisfying `maintainers`.
