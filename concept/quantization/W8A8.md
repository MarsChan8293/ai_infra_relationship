# W8A8

## 一句话定义

W8A8 表示权重和 activation 都以 8bit 精度参与主要计算，是 LLM inference 中常见的低精度 GEMM 部署形态。

## 不是一种唯一格式

W8A8 只描述“bit width 组合”，并不指定底层格式。常见实现包括：

- INT8 weight + INT8 activation。
- FP8 E4M3 / E5M2。
- MXFP8 等 microscaling format。

因此比较 W8A8 性能时必须同时说明 dtype、scale granularity、kernel backend 和 hardware。

## 核心机制

权重通常离线量化；activation 可以 static calibration，也可以在运行时动态计算 per-token/per-tensor scale。支持原生 8bit tensor core 的设备可以直接执行低精度 GEMM，否则可能退化为 dequant + 高精度计算。

## 与 Weight-Only 的区别

[[Weight-Only Quantization]] 的 activation 保持 16bit 左右；W8A8 进一步减少 activation bandwidth 和 compute datatype，但通常更容易受到 activation outlier 和 scaling 策略影响。

## 项目实现

[[community/vllm-project/vLLM/vLLM|vLLM]] 支持 FP8/INT8 W8A8，并按硬件选择 DeepGEMM、CUTLASS、Marlin、Triton 等 backend；[[community/Ascend/msModelSlim/msModelSlim|msModelSlim]] 广泛提供昇腾模型 W8A8 量化实践；[[community/deepseek-ai/DeepSeek-Infra/DeepGEMM|DeepGEMM]] 为 FP8/低精度 W/A 计算提供高性能 kernel。
