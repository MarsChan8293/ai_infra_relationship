# 学校与研究机构

本目录汇总高校、实验室与研究机构，用来表达导师学生、大学同学、实验室同门、访问研究、论文合作与人才培养关系。

## 已实体化 AI Infra 学术网络
- [[Tsinghua University]]：包含 MADSys / KVCache、KEG / GLM、PACMAN / vLLM 等不同谱系，连接 KTransformers、Mooncake、Zhipu、Kimi、vLLM、Inferact、Approaching.AI、Qingcheng.ai 等节点。
- [[UC Berkeley]]：Sky / RISE / AMPLab 系统网络，连接 Ray / Ray Serve、vLLM、SGLang、Inferact、Anyscale、Databricks 与多家 frontier labs 的人才流动。
- [[Shanghai Jiao Tong University]]：IPADS Modern AI Infrastructure 与 NNE-Lab / LightLLM 等系统研究网络，连接 serving resource management、KV cache 与推理系统产业化。
- [[Peking University]]：AI compiler / kernel DSL 谱系，从 Rammer、Welder 延伸到 TileLang，并连接 MSRA、NVIDIA、ByteDance 等工程与研究网络。
- [[Microsoft Research Asia]]：微软亚洲研究院 systems / AI research 网络，连接北大 compiler / TileLang、vLLM、SGLang、DeepSeek、OneFlow / SiliconFlow 等人才路径。

## 规则
- 只有能确认同期和具体培养关系时，才写“同学 / 同门”。
- 导师学生关系尽量记录学校、实验室与起止年份。
- 已经高频出现且有实体页的学校或研究机构必须进入本一级入口；尚未实体化的高频机构只列为后续补充。
