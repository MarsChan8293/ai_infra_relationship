# Yongxiang Huang

## 身份解析
vLLM-Omni governance 中的 `@SamitHuang` 与 VeRL-Omni governance 的 lead maintainer **Yongxiang Huang** 是同一 GitHub 身份。其公开 GitHub 资料写明为 HKUST CSE PhD graduate，因此保留 [[university/香港科技大学/香港科技大学|香港科技大学]] 教育关联，但本轮不猜当前雇主。

## vLLM-Omni
官方 Active Committer，职责为 **RL, Diffusion, and cache**；也是 vLLM-Omni 2026 fully-disaggregated serving 论文作者。

## VeRL-Omni
[[community/verl-project/VeRL-Omni/VeRL-Omni|VeRL-Omni]] 官方两位 Lead Maintainer 之一。该项目用 vLLM-Omni 作为 multimodal/diffusion rollout backend，将高性能 inference engine 直接接入 RL post-training loop。

这使 Yongxiang Huang 成为一个非常有价值的跨层桥：

`vLLM-Omni serving → rollout/cache → VeRL-Omni → multimodal/diffusion RL post-training`
