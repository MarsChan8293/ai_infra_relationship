# KTransformers

## 项目简介
KTransformers 是面向 heterogeneous LLM inference / fine-tune 优化的框架，尤其关注 CPU+GPU、多 NUMA 节点和多设备协同，让超大模型可以利用 CPU 内存与计算能力补足 GPU 显存/算力约束。它代表一条不同于“全 GPU 数据中心 serving”的本地与异构推理路线。
