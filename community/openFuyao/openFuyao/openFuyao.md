# openFuyao（开源扶摇）

面向多样化算力集群的云原生开源社区，覆盖 Kubernetes 编排、异构资源管理、NPU DRA 与 AI 原生推理服务。

## 推理相关项目
- [[community/openFuyao/InferNex/InferNex|InferNex]]：云原生分布式 LLM 推理加速套件，集成智能路由、PD 编排、弹性伸缩、KV Cache 与可观测性。
- 与 [[MindIE-Motor]]、[[AIBrix]]、[[llm-d]]、[[KServe]] 在服务管理层存在可比较能力，但不等同于推理执行引擎。
