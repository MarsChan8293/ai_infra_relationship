# HAMi Ascend Device Plugin

## 项目简介
HAMi Ascend Device Plugin 是 Project-HAMi 面向 Ascend NPU 的设备插件与调度扩展，承接 Ascend/vNPU 资源发现、设备分配与细粒度调度能力。它是 [[community/Project-HAMi/HAMi/HAMi|HAMi]] 在昇腾设备生态中的明确组件节点，因此单独实体化以承接 reviewer / approver 等治理关系。
