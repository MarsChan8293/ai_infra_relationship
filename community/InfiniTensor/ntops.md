# ntops

ntops 是 NineToothed operators for LLMs，将 [[NineToothed]] 的 DSL / compiler 抽象落到可复用 LLM operators。

该仓库包含较多教学 / 社区任务型贡献，因此不把所有 PR 作者直接提升为核心维护者。[[GordonYang1]] 同时在 ntops 与 [[InfiniCCL]] / [[InfiniCore]] 有直接工程贡献，是少数具有跨组件价值的桥节点。
