# DeepSpark 开源社区

DeepSpark 是由天数智芯与行业伙伴共同建设的 AI / 通用计算开源社区。官方 README 明确采用“平台共建、生态共享、产业共赢”的社区定位，并提供 Code of Conduct、贡献指南和开发者交流入口。

## 推理侧核心节点
[[DeepSparkInference]] · [[iluvatar-corex-ixrt]] · [[lmcache-iluvatar]]。

DeepSparkInference 同时覆盖 IGIE / ixRT 与 vLLM 等主流开源推理引擎，因此它是观察国产 GPU 软件栈如何接入上游 inference ecosystem 的重要桥。
