# DeepSparkInference

DeepSparkInference 是 [[DeepSpark]] 的核心推理项目，覆盖 CV / NLP / speech 与大语言模型，在天数智芯 GPU 上同时提供 IGIE、ixRT 以及 vLLM 等主流开源推理路径。

## AI Infra 位置
- IGIE：基于 TVM 的推理引擎路径。
- ixRT：天数智芯高性能推理 runtime。
- LLM：公开示例持续覆盖 vLLM，并与模型 / runtime 版本演进同步。
