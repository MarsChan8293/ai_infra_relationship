# Ziyue Yang

Ziyue Yang 是 [[community/yzygitzh/RoofLang/RoofLang|RoofLang]] 的通讯作者，也是公开 GitHub 仓库中当前可以直接核验到的主要代码 / 文档提交者之一。RoofLang arXiv v2 将其 affiliation 明确标为 **Shanghai Xingyunzhili Artificial Intelligence Institute**。

## AI Infra 研究轨迹

其公开研究轨迹具有较强连续性：

- **SuperBench**：2024 年 USENIX ATC Best Paper 作者之一，工作聚焦 cloud AI infrastructure proactive validation；当时 USENIX 作者信息将其列为 Microsoft Research。
- **SIGMA**：2025 年 AI-empowered training stack 作者之一，面向 early-life accelerator 的可靠性、稳定性与效率。
- **RoofLang**：2026 年把系统研究推进到 implementation-independent LLM inference architecture search，让 AI agent 可以在 graph transformation、placement、parallelism、memory / communication choices 上闭环探索。

这条谱系说明其研究重点从 AI infrastructure reliability / systems 逐步延伸到 AI-driven inference architecting。
