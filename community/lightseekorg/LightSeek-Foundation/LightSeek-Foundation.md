# LightSeek Foundation

## 社区定位
LightSeek Foundation 是围绕开放 LLM inference 基础设施与工程协作形成的 foundation/community 节点。2026 年持续发布并协作推进 [[TokenSpeed]]、TorchSpec、SMG 等推理系统工作，重点覆盖 agentic inference、speculative decoding、kernel/runtime 与 serving frontend。

## AI Infra 主线
- [[TokenSpeed]]：面向 agentic workloads 的高性能 LLM inference engine。
- TorchSpec：面向 speculative decoding 的可扩展训练框架。
- SMG：将 CPU-bound serving frontend 与 GPU inference engine 解耦的 gateway/runtime 路线。
