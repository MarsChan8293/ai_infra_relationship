# LightLLM

## 项目简介
LightLLM 是 Python-based 的高性能 LLM inference / serving framework，强调轻量、可扩展与模型/硬件适配。它与 vLLM、SGLang 同属 serving engine 层，但形成了独立的调度、kernel 与模型支持技术路线。
