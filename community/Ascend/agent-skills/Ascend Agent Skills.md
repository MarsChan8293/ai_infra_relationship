# Ascend Agent Skills

Ascend Agent Skills 是昇腾官方的 Agent Skill 仓库，把 Ascend 软件栈专家经验封装为可复用技能，供 OpenCode、Claude Code、TRAE 等 coding agent 使用。

## 与性能优化相关的能力

公开 Skill 覆盖 AscendC、Catlass、Triton 算子开发与性能优化，包括代码生成、性能评估、性能优化、精度验证、profiling 异常分析、GPU→Ascend 迁移等工作流。

它不是单一 autonomous optimizer runtime，但非常适合作为 Ascend Kernel Agent 的 **Domain Knowledge / Skill Layer**。
