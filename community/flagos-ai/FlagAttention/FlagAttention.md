# FlagAttention

## 项目简介
FlagAttention 是 FlagOS 面向 attention 场景的 Triton 算子项目，聚焦显存友好和可扩展的注意力实现，并服务多后端适配。相比通用算子库 [[FlagGems]]，它更集中在大模型 attention 热点，因此与推理性能优化直接相关。

## GitHub
https://github.com/flagos-ai/FlagAttention

## 主要维护者 / 组织
由 FlagOS 社区维护。[[陈飞宇]] 的智源公开主页明确将其列为 FlagGems 与 FlagAttention 项目开发者；不据此推断其为唯一负责人或当前治理 maintainer。

## 生态关系
[[FlagOS]] · [[FlagGems]] · [[FlagTree]] · [[FlagScale]] · [[FlashInfer]]。与 FlashInfer 的链接表达同属 attention/kernel 优化层的技术邻接，不表示共同治理。
