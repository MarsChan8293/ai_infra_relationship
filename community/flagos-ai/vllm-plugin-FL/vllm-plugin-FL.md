# vllm-plugin-FL

## 项目简介
vllm-plugin-FL 是 FlagOS 面向 [[vLLM]] 的多芯片适配插件，把 FlagOS 的统一多后端能力接入 vLLM serving 生态。它是智源/FlagOS 与本仓库既有 vLLM 人才网络之间最直接的项目级桥梁之一。

## 主要维护者 / 组织
由 flagos-ai / FlagOS 社区维护。该页只记录插件与 vLLM 的技术关系，不把插件贡献者自动写成 vLLM core maintainer。
