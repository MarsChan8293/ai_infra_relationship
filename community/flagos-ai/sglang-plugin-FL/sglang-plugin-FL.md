# sglang-plugin-FL

## 项目简介
sglang-plugin-FL 是 FlagOS 面向 [[SGLang]] 的 out-of-tree 多芯片适配插件，借助 FlagOS 的算子、通信与多后端能力，让 SGLang 在更多硬件后端上复用统一接口。

## GitHub
https://github.com/flagos-ai/sglang-plugin-FL

## 主要维护者 / 组织
由 flagos-ai / FlagOS 社区维护。插件兼容关系不能自动推断为 FlagOS 开发者与 SGLang core 团队存在公司同事关系。
