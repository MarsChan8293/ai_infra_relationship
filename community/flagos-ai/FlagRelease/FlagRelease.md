# FlagRelease

## 项目简介
FlagRelease 是 FlagOS 的模型跨芯迁移与发版工具，目标是把模型在不同 AI 加速芯片上的适配、依赖、镜像与发布流程产品化。对推理生态而言，它更接近“把优化后的系统栈交付成可直接部署版本”的工程层。

## GitHub
https://github.com/flagos-ai/FlagRelease

## 主要维护者 / 组织
由众智 FlagOS 社区维护；智源公开资料将其作为 FlagOS 全栈工具链的重要组成部分。
