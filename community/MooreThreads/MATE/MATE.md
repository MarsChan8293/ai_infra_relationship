# MATE

MATE（MUSA AI Tensor Engine）是摩尔线程开源的高性能 AI 算子 / tensor engine，服务 MUSA GPU 上的模型执行与推理优化。

2026-09 摩尔线程官方开发者站宣布 MATE 开源，将其作为释放 MUSA GPU 算力能力的重要 kernel / operator 层组件。
