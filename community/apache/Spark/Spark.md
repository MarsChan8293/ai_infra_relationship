# Apache Spark

Apache Spark 起源于 UC Berkeley AMPLab，是 Berkeley systems “研究 → 开源 → 公司”谱系里最经典的项目之一，也是理解 [[company/Inferact/Ion Stoica|Ion Stoica]] 早期技术与创业网络的关键节点。

## 图谱意义
- [[university/UC Berkeley/Matei Zaharia|Matei Zaharia]]：Spark 原始创建者，UC Berkeley 博士阶段由 Scott Shenker 与 Ion Stoica 共同指导。
- [[university/UC Berkeley/Reynold Xin|Reynold Xin]]：Berkeley 分布式数据系统研究者，后成为 Databricks 联合创始人 / Chief Architect。
- [[company/Databricks/Databricks|Databricks]]：Spark 核心团队产业化形成的重要公司节点。

这条线构成：
`Berkeley AMPLab → Spark → Databricks`，与后来的 `RISELab → Ray → Anyscale`、`Sky → vLLM / SGLang → Inferact` 一起形成 Ion Stoica 周围连续多代 systems 产业化谱系。
