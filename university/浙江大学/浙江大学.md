# 浙江大学

## AI Infra 总览
对本仓库关注的 **LLM inference / serving / kernel / memory optimization** 而言，浙江大学并不是只有 [[梁文锋 Liang Wenfeng]] 这一条 DeepSeek 校友线。当前已经能形成一条相当清晰的 **数据库 / 数据智能 → 高效 AI → LLM inference systems** 学术主线，并向 [[Together AI]]、[[NVIDIA]] / [[FlashInfer]]、[[深度求索]] 等产业与开源节点外溢。

当前最值得跟踪的几条线：

1. **数据库 / SuDIS → LLM inference systems**：[[Lidan Shou]]、[[Huan Li]] 团队近年的工作已经直接覆盖 multi-tenant inference、MoE inference、speculative decoding、KV-cache compression 与多模态推理加速。
2. **MoE memory / data movement**：[[Zheng Li]] 等人的 **FloE**（ICML 2025）针对显存受限 GPU 上的 MoE 推理，通过专家压缩、稀疏预测与数据搬运优化降低 PCIe / 显存瓶颈。
3. **校友 → 产业 inference research**：[[Jue Wang]] 从浙大博士网络进入 [[Together AI]]，研究继续覆盖 tensor parallelism、FloE、multi-tenant inference 等系统问题。
4. **校友 → GPU kernel / serving ecosystem**：[[Jingfan Sun]] 本科毕业于浙大，当前在 [[NVIDIA]] 并作为 [[FlashInfer]] Full Codebase Approver，连接 GPU kernel、MoE/EP 与 vLLM/SGLang 等 serving interface。
5. **校友 → DeepSeek**：[[梁文锋 Liang Wenfeng]] 本硕毕业于浙大，后创办 [[深度求索]]；这条线把浙大节点直接接到 DeepSeek 的 MoE、MLA、DeepEP、DeepGEMM 与开源模型/infra 网络。

## 寿丽丹 / 李环系：数据库与数据智能 → 推理系统
### HMI：multi-tenant inference
[[Lidan Shou]]、[[Huan Li]]、[[Jue Wang]] 等共同参与 HMI，研究如何在单 GPU 上高效服务大量不同 pretrained models / tenants。其核心不是传统数据库查询优化，而是把知识层级、参数存储、prefetch 与 GPU 计算流水线结合，直接进入 inference serving 的资源管理问题。

### FloE：memory-constrained MoE inference
ICML 2025 的 **FloE** 由 Yuxin Zhou、[[Zheng Li]] 等人与 [[Lidan Shou]] 团队完成，目标是在显存受限 GPU 上运行 MoE。它围绕 expert 参数搬运、压缩与预测减少 PCIe 压力，是典型的 **memory / communication-bound inference optimization**。

### Speculative decoding / KV cache
2026 年该网络继续向现代 LLM inference 扩展：
- **TokenTiming**（ACL 2026）：[[Lidan Shou]] 等研究跨 tokenizer / vocabulary 的通用 speculative decoding，报告最高约 1.57× 加速。
- [[Huan Li]] 团队公开研究路线还包括 Draft & Verify、ParallelVLM 等 speculative / parallel decoding，以及 HybridKV、HARD-KV 等 KV-cache compression 工作。

这说明浙大这条线已经从“数据库 + Efficient AI”明显转入 inference engine 关心的核心问题：**显存、KV cache、prefill/decode、multi-tenancy、MoE offload 与 speculative decoding**。

## 产业与开源外溢
### DeepSeek
[[梁文锋 Liang Wenfeng]] 是最醒目的产业校友节点。浙江大学官方资料明确记载其本硕毕业于信息与电子工程学院；其后创办 DeepSeek，使浙大校友网络直接连接到当代大模型训练和推理基础设施。

### NVIDIA / FlashInfer
[[Jingfan Sun]] 本科阶段在浙江大学，之后进入 Georgia Tech 并任职 [[NVIDIA]]。其当前 [[FlashInfer]] Full Codebase Approver 身份，使浙大节点直接进入 GPU kernel、MoE/EP、attention/GEMM 与高性能 serving 生态。

### Together AI
[[Jue Wang]] 在浙江大学完成本科和计算机博士训练，博士导师为 [[Lidan Shou]]；目前在 [[Together AI]] 从事研究。其论文网络继续连接 tensor parallelism、MoE inference 和 multi-tenant inference。

## 其他值得继续 BFS 的点
- **张杰（Jie Zhang）**：浙江大学软件学院百人计划研究员，官方主页直接列出“计算机系统结构、网络 / 大模型推理 / 具身智能系统”。目前公开资料还不足以把他与本仓库既有 serving/kernel 项目建立强关系，先作为后续 BFS 候选。
- **SuDIS / 浙江大学数据库与数据智能实验室**：2026 年公开路线已连续覆盖 speculative decoding、KV-cache compression、多模态 inference acceleration，后续值得从论文作者与实习/就业去向继续展开。

## 图谱洞察
浙江大学当前最有辨识度的地方，不是某一个单点项目，而是出现了三层叠加：

**校内 systems / data intelligence research → inference optimization 论文与原型 → 杭州及全球 AI infra 产业网络。**

其中，[[Lidan Shou]] / [[Huan Li]] 这一支把数据库系统传统里的 memory hierarchy、resource sharing、data movement 与现代 LLM serving 问题接上；[[梁文锋 Liang Wenfeng]]、[[Jingfan Sun]]、[[Jue Wang]] 则把这条学术/教育网络向 DeepSeek、NVIDIA/FlashInfer、Together AI 扩散。对“推理优化人才图谱”来说，浙大已经足够成为一级学校节点，而不是只保留红链。
