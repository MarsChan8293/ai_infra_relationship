# 浙江大学

## AI Infra 总览
对本仓库关注的 **LLM inference / serving / kernel / memory optimization** 而言，浙江大学并不是只有 [[梁文锋 Liang Wenfeng]] 这一条 DeepSeek 校友线。当前已经能形成一条相当清晰的 **数据库 / 数据智能 → 高效 AI → LLM inference systems** 学术主线，并向 [[Together AI]]、[[NVIDIA]] / [[FlashInfer]]、[[深度求索]] 等产业与开源节点外溢。

## SuDIS：Data Systems → Efficient AI → Inference Systems
[[university/浙江大学/SuDIS|SuDIS]] 是浙江大学 Sustainable Data Intelligence and Data Systems research group。李环官方主页明确把它称为“我们的课题组（SUDIS Lab）”，研究方向包括 Data-centric AI 与 Efficient AI。

本图谱重点跟踪其中已经进入 inference systems 的工作：
- [[university/浙江大学/HMI|HMI]]：multi-tenant inference 的模型知识层级、parameter swapping、prefetch 与流水线优化；
- [[university/浙江大学/FloE|FloE]]：memory-constrained GPU 上的 MoE expert 压缩、预测与参数搬运；
- speculative decoding、KV-cache compression、多模态 inference acceleration 等后续研究线。

### 核心人物
- [[Lidan Shou]]：浙江大学数据库 / 数据智能与 inference systems faculty 节点。
- [[Huan Li]]：当前公开研究路线直接覆盖 speculative decoding、KV cache、多租户 serving 与 serving stack 优化。
- [[Jue Wang]]：浙大博士校友，后进入 [[Together AI]]；参与 HMI、FloE、Ladder Residual 等 inference work。
- [[Zheng Li]]：[[university/浙江大学/FloE|FloE]] 共同第一作者之一。

## 产业与开源外溢
### DeepSeek
[[梁文锋 Liang Wenfeng]] 本硕毕业于浙江大学，后创办 [[深度求索]]；这条线把浙大校友网络直接连接到 DeepSeek 的 MoE、MLA、DeepEP、DeepGEMM 与开源模型/infra 网络。

### NVIDIA / FlashInfer
[[Jingfan Sun]] 本科阶段在浙江大学，之后进入 Georgia Tech 并任职 [[NVIDIA]]。其当前 [[FlashInfer]] Full Codebase Approver 身份，使浙大节点直接进入 GPU kernel、MoE/EP、attention/GEMM 与高性能 serving 生态。

### Together AI
[[Jue Wang]] 在浙江大学完成本科和计算机博士训练，博士导师为 [[Lidan Shou]]；目前在 [[Together AI]] 从事研究，其论文网络继续连接 tensor parallelism、MoE inference 和 multi-tenant inference。
