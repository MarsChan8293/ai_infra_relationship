# MADSys

## 机构定位
MADSys 是清华大学计算机系面向 Machine Learning / AI / Big Data Systems 的系统研究团队。在本图谱中，它是清华 systems 人才进入现代 LLM inference 基础设施的重要上游节点，尤其连接 memory/storage-centric inference、KV cache、异构执行与大规模 serving。

## AI Infra 主线
- [[community/kvcache-ai/Mooncake/Mooncake|Mooncake]]：KVCache-centric disaggregated serving 与分布式缓存/传输系统。
- [[community/kvcache-ai/KTransformers/KTransformers|KTransformers]]：CPU/GPU/NUMA 异构推理与本地超大模型执行。
- 团队人才进一步流向趋境科技、DeepSeek 等 AI Infra / frontier-model 工程组织。
