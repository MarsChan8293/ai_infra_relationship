# Weichao Guo

OPPO OS Kernel Team Principal Engineer。此前曾在 Huawei OS Kernel Lab 与 Alibaba Cloud Storage Team 工作，研究方向覆盖操作系统、存储与移动系统。

博士毕业后的路径把清华 systems 人才网络连续连接到：
