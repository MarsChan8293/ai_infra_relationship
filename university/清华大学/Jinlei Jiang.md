# 蒋金磊（Jinlei Jiang）

清华大学计算机系副教授、[[university/清华大学/MADSys|MADSys]] faculty。官方主页将其研究兴趣概括为 distributed computing and systems、cloud computing、big data、machine learning、SDN 与 virtualization。

## 教育与任职
- 1999：清华大学计算机科学与技术学士。
- 2004：清华大学计算机科学与技术博士。
- 2004–2011：清华大学计算机系助理教授。
- 2011–至今：清华大学计算机系副教授。

## 与 MADSys AI Infra 主线的关系
蒋金磊不是当前 KVCache / LLM serving 项目的核心作者，但属于 MADSys 的长期 systems faculty，与 [[company/趋境科技/武永卫 Yongwei Wu|武永卫]]、[[university/清华大学/Mingxing Zhang|章明星]]、[[university/清华大学/Yingdi Shan|闪英迪]]持续合作。

2025–2026 的公开论文中，其合作网络覆盖 OSDI 2025 `Scalio`（DPU / NVMe-oF key-value store）以及 SIGMOD 2026 `Accelerating Stream Processing Engines via Hardware Offloading`。这些工作对应 MADSys 的另一条底层系统支路：data processing / storage / hardware offloading，为实验室后来围绕异构硬件和数据移动的 AI Infra 路线提供系统背景。

## 图谱意义
在人才图谱中，蒋金磊更适合作为 MADSys faculty 骨架节点，而不是强行归入 LLM inference 人才。他帮助区分两层关系：上层的 Mooncake / KTransformers / Seer 与下层长期存在的 storage、cloud、DPU/offloading 系统研究。
