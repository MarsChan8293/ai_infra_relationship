# FlexFlow Serve

FlexFlow Serve 是 Catalyst 官方研究页面列出的 low-latency, high-performance generative LLM serving system。

## AI Infra 位置
- 以 compiler / distributed runtime 路线优化多 GPU LLM serving。
- 公开研究覆盖 tree-based speculative inference、CPU offloading 与 quantization。
