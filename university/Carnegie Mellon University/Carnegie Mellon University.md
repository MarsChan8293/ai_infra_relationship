# Carnegie Mellon University

## AI Infra 关系
Carnegie Mellon University（CMU）是本图谱中的 AI / systems 人才源头之一。当前新增 [[university/Carnegie Mellon University/Catalyst Group|Catalyst Group]]，把 compiler、runtime、LLM serving、structured generation 与 heterogeneous inference 的研究网络正式接入图谱。

## Catalyst / ML Systems
Catalyst 是 CMU 跨 Machine Learning、Computer Science 与 ECE 的 automated learning systems research group。与本仓库最相关的公开项目包括 FlexFlow Serve、XGrammar、TidalDecode、MLC LLM、Mirage Persistent Kernel；其 publication network 还包含 Helix、FlashInfer、GraphPipe 等系统工作。
