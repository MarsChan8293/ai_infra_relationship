# Xin Jin

北京大学计算机学院长聘副教授，研究方向覆盖 computer systems / networking，并明确把 cloud computing 与 large language model training / serving systems 作为当前重点。

## 刘胜与关系
[[community/deepseek-ai/DeepSeek-Infra/刘胜与 Shengyu Liu|刘胜与（Shengyu Liu）]] 的个人主页和 CV 都明确写明其在北京大学 Computer Systems Research Group 由 Xin Jin 指导。两人还共同署名 DistServe（OSDI 2024）、LoongServe（SOSP 2024）以及后续多项 LLM systems 工作，因此这是**导师 + 长期系统研究合作**的强关系，不是仅凭同校推断。

## LLM systems 路线
- [[community/LLMServe/DistServe/DistServe|DistServe]]：prefill/decode disaggregation。
- [[community/LoongServe/LoongServe/LoongServe|LoongServe]]：elastic sequence parallelism for long-context serving。
- 该研究组还持续发展 FastServe、RLHFuse、dLoRA、MegaScale-Infer 等训练 / serving 系统。
