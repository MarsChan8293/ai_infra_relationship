# 马凌霄（Lingxiao Ma）

北大 → MSRA AI compiler 人才链中的关键桥梁。个人主页显示其 2020 年获北京大学 Computer Architecture 博士，导师为 Yafei Dai 与 [[杨智 Zhi Yang]]；后在 Microsoft Research Asia 从事 Systems for Machine Learning 研究。

## Compiler 系统谱系
其公开主页列出的主要系统包括：
- **Rammer（OSDI 2020）**
- **Roller（OSDI 2022）**
- **Welder（OSDI 2023）**
- **Cocktailer（OSDI 2023）**
- **T10（SOSP 2024）**
- BitBLAS / Ladder、T-MAC 等后续 kernel / low-bit execution 工作

这些系统使其成为从北大早期 DNN compiler 到现代 LLM kernel DSL 的连续技术节点。

## TileLang
[[TileLang]] 官方仓库明确感谢 Lingxiao Ma、Yuqing Xia、Jilong Xue、Fan Yang 在 Microsoft Research 阶段提供指导和支持；其也是 TileLang ICLR 2026 与 PipeThreader OSDI 2025 作者。
