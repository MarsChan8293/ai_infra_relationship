# Yining Shi

北大 AI compiler / TileLang 谱系的重要人物。公开论文记录显示其曾以 Peking University / Microsoft Research 身份开展 compiler systems 研究，后续公开资料显示进入 [[NVIDIA]]。

## 代表工作
- **Welder（OSDI 2023）**：第一作者。Welder 用 tile-graph 对深度学习执行的 memory access、operator fusion 与 data reuse 进行联合优化，是从 Rammer 走向 TileLang 的关键中间节点。
- [[TileLang]]：官方仓库列出的初版主要开发者之一；ICLR 2026 Oral 作者。
- **PipeThreader（OSDI 2025）**：与 [[程羽 Yu Cheng]]、[[Lei Wang]]、MSRA 团队合作。

## 关系
- [[杨智 Zhi Yang]]：Welder / TileLang 学术网络核心。
- [[马凌霄 Lingxiao Ma]]、Yuqing Xia、Jilong Xue、Fan Yang：MSRA compiler systems 合作网络。
- [[NVIDIA]]：OpenReview 公开履历列为 2024–至今 Researcher，形成北大 compiler → GPU platform 的人才桥。
