# Tile-AI

## 机构定位
Tile-AI 是北京大学 AI compiler / kernel DSL 研究与开源团队节点，连接高性能 AI kernel、编译器、分布式编程与 LLM inference 系统工作。

## 核心项目
- [[TileLang]]：高性能 GPU/CPU/accelerator kernel DSL；官方仓库将 LeiWang1999、程羽等列为初始版本主要开发者，并注明由北京大学杨智指导。
- TileScale：面向 distributed programming / communication 的系统项目。
- TileOps：高性能 operator library。

## 关系边界
Tile-AI 成员关系表示公开的研究/开源团队参与，不自动推出正式雇佣、导师或同期同学关系；具体导师与论文合作仍以人物页证据为准。
