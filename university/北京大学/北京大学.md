# 北京大学

## AI Infra 总览
北大的 AI Infra 网络不只是一条 serving 线。本轮先实体化最清晰的 **AI compiler / kernel DSL** 谱系：[[杨智 Zhi Yang]] → Rammer / Welder → [[TileLang]]。这条线长期与 Microsoft Research Asia 共研，并正在向 NVIDIA、ByteDance 以及现代 LLM kernel/runtime 生态扩散。

与此同时，仓库里已经存在多位北大背景人物，例如 [[李卓翰 Zhuohan Li]]、[[柳晓萱 Xiaoxuan Liu]]、[[杜昆泰 Kuntai Du]]、[[程翊华 Yihua Cheng]]、[[周可行 Kexing Zhou]]、[[刘胜与 Shengyu Liu]]。因此北大节点天然连接 Berkeley/vLLM、OpenAI、UChicago/LMCache/TensorMesh 与 DeepSeek kernel 生态，后续可以继续从这些人物反向 BFS。

## 杨智系：AI Compiler → Kernel DSL
### 1. Rammer
[[杨智 Zhi Yang]] 与 [[马凌霄 Lingxiao Ma]]、MSRA 合作的 Rammer（OSDI 2020）从编译期统一调度 DNN operator 内外并行，把 AI compiler 从“调用黑盒算子库”推进到更整体的 accelerator scheduling。

### 2. Welder
[[Yining Shi]] 作为第一作者、杨智与 MSRA 团队合作的 Welder（OSDI 2023）进一步采用 tile-graph，从 memory access 视角处理算子融合、数据复用与 memory hierarchy。

### 3. TileLang
[[TileLang]] 将这条思路推向现代 AI kernel 编程：通过 tile-level primitives 和 compiler inference/recommendation，让开发者直接表达 GEMM、FlashAttention、MLA decoding 等 kernel，同时保留底层硬件控制能力。ICLR 2026 收录为 Oral。

核心北大人物：
- [[杨智 Zhi Yang]]：faculty / academic hub，研究 AI computing systems、distributed systems。
- [[Lei Wang]]：TileLang 第一作者与初版主要开发者之一。
- [[程羽 Yu Cheng]]：杨智学生、TileLang core developer；MSRA systems research intern；TileScale developer。
- [[Yining Shi]]：Welder 第一作者、TileLang 初版主要开发者；后进入 NVIDIA。
- [[吴童 Tong Wu]]：杨智指导的年轻系统研究者，贡献 TileLang、TileScale、TileOps，并研究 LLM training/inference co-design。
- [[马凌霄 Lingxiao Ma]]：北大博士校友，杨智/代亚非指导；在 MSRA 延续 Rammer、Roller、Welder 等 compiler 系统路线并参与 TileLang 指导。

## 关键跨组织路径
**北大杨智组 → MSRA Systems → TileLang** 是当前最强的共研主线；[[Yining Shi]] 又把它连接到 [[NVIDIA]]，[[吴童 Tong Wu]] 连接到 [[字节跳动]]。

另一条值得后续继续深挖的交叉路径是：北大 alumni → Berkeley / UChicago / DeepSeek。仓库现有 [[李卓翰 Zhuohan Li]]、[[柳晓萱 Xiaoxuan Liu]]、[[杜昆泰 Kuntai Du]]、[[程翊华 Yihua Cheng]]、[[周可行 Kexing Zhou]]、[[刘胜与 Shengyu Liu]] 已经提供多个 BFS 起点。

## 图谱洞察
北大 compiler 系的特点不是只做 graph compiler，而是连续把抽象往硬件执行层下沉：Rammer 关注调度，Welder 关注 tile-level memory traffic，TileLang 进一步把 tile 暴露成可编程语言抽象。这条线与今天 LLM inference 的 attention/GEMM/quantization kernel 高度重叠，因此它会自然连接 [[FlashInfer]]、DeepGEMM、Triton、[[vLLM]]、[[SGLang]] 等项目，而不是停留在传统 DL compiler 时代。
