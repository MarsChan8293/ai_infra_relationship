# Matei Zaharia

Apache Spark 原始创建者、Databricks 联合创始人 / CTO、Stanford 教授，同时是 UC Berkeley Sky Computing Lab core faculty。

## 学术谱系
- UC Berkeley CS PhD，2007–2013。
- 博士论文《An Architecture for Fast and General Data Processing on Large Clusters》。Berkeley 官方档案明确列出导师为 Scott Shenker 与 [[company/Inferact/Ion Stoica|Ion Stoica]]。
- [[community/apache/Spark/Spark|Spark]] 是这段 Berkeley systems 研究的核心产物。

## AI Infra 连接
- [[company/Databricks/Databricks|Databricks]]：联合创始人，长期连接 Spark / data systems 与现代 data + AI platform。
- [[university/UC Berkeley/Sky Computing Lab|Sky Computing Lab]]：当前 core faculty，继续参与 AI systems / inference / AI-driven systems 研究。
- [[university/UC Berkeley/MoE-Lightning|MoE-Lightning]]、[[community/FlashML-org/FreeToken/FreeToken|FreeToken]] 等新一代工作把早期 distributed data systems 谱系重新连接到 LLM / MoE inference。

## 图谱意义
Matei Zaharia 是 Ion Stoica 网络里非常重要的“跨代桥”：
`Spark / Databricks → Sky → modern AI systems`。
