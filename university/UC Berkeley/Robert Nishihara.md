# Robert Nishihara

Ray creator、Anyscale 联合创始人，UC Berkeley distributed ML systems 网络的重要产业化人物。

## 学术关系边界
Robert Nishihara 的 Berkeley 博士论文《On Systems and Algorithms for Distributed Machine Learning》官方档案列出的博士导师是 **Michael Jordan**。因此本图谱不把 [[company/Inferact/Ion Stoica|Ion Stoica]] 标成其正式博士导师。

Ion ↔ Robert 的强边来自另一层：
- 共同创建 / 推动 [[community/ray-project/Ray/Ray|Ray]]；
- 共同创办 [[company/Anyscale/Anyscale|Anyscale]]；
- 长期 Berkeley RISELab / distributed AI systems 协作。

## 图谱意义
Robert 是检验关系语义的重要案例：同一个 Berkeley systems 创始网络里，`cofounder + research/open-source collaboration` 不应被偷换成 `advisor/student`。
