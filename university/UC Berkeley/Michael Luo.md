# Michael Luo

UC Berkeley EECS PhD alumnus，研究从 LLM serving 延伸到 agent post-training / RL systems，是 Ion Stoica 新一代“serving → agent infrastructure”谱系的重要节点。

## 学术谱系
- UC Berkeley PhD，2021–2025。
- Berkeley 官方 2025 dissertation 页面明确列出论文《From Serving to Training: Efficient Systems for LLM Agents at Scale》，导师为 [[company/Inferact/Ion Stoica|Ion Stoica]]。
- 论文覆盖 Agentix 等 application-aware agent serving / scheduling 系统。

## Agent systems
Michael Luo 创建 Agentica Project，后续公开工作覆盖 rLLM、DeepScaleR、DeepCoder、DeepSWE，把 Berkeley Sky 的 systems 方法从单次 LLM serving 推到大规模 agent post-training 与 coding agents。

个人主页显示其曾在 Google DeepMind 从事 efficient agentic systems for serving and post-training；截至 2026-09 公开描述为正在构建 stealth startup，因此本图谱不猜测公司名称。

## 图谱意义
`Ion Stoica → Michael Luo → serving / Agentix → Agentica / rLLM → agent training systems`

这是 Ion 网络从 vLLM / SGLang 之后继续向 agent infrastructure 生长的一条新支线。
