# 微软亚洲研究院

## 机构简介
微软亚洲研究院（MSRA）成立于 1998 年，是 Microsoft Research 在亚太地区的重要研究机构。当前在北京、上海、温哥华、东京、新加坡、香港等地设有实验室或研究岗位，研究方向覆盖 computing fundamentals、AI、multimodal、systems 与产业/科学应用。

在本图谱里，MSRA 不是泛化的“微软经历”节点，而是一条很清晰的 AI Infra 人才中转站：一侧连接北京大学 compiler / kernel DSL 研究，另一侧连接 vLLM、SGLang、DeepSeek、OneFlow / SiliconFlow 等后续人才流向。

## 项目 / 学术网络
- [[北京大学]]：Rammer、Welder、[[TileLang]] 等 compiler / kernel 研究长期存在共同研究与实习指导关系。
- [[TileLang]]：当前图谱中最直接的 compiler genealogy 连接之一，体现 MSRA systems research 对现代 LLM kernel/runtime 人才的上游影响。

## 关系边界
同在 MSRA 有研究/实习经历不等于同期同事或同组成员。人物之间只有在公开资料能确认具体导师、共同论文、共同项目或重叠团队时，才进一步建立直接关系边。
