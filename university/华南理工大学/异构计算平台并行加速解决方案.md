# 异构计算平台并行加速解决方案

这是华南理工大学陆璐团队与 [[company/超聚变/超聚变|超聚变]] 在异构加速领域公开展示的联合创新方案。

## 技术栈

公开案例明确描述了以下层次：

- **硬件**：鲲鹏 + 昇腾异构平台；
- **基础软件**：openEuler / FusionOS；
- **算子层**：BLAS / GEMM、FFT 等核心算子优化；
- **benchmark**：HPL、HPL-AI；
- **AI deployment**：模型部署与算子迁移调优；
- **通信**：多卡、多节点通信与千卡 / 千节点并行性能优化；
- **迁移**：将应用从国外平台生态迁移至国产计算平台。

超聚变与华南理工公开材料称双方共同优化底层算子的运行效率，并在 openEuler 生态中进行迁移研究和实践。

## 与 Ascend 图谱的关系

该方案明确使用 **Ascend NPU**，因此它是仓库里学校侧连接昇腾硬件的一条直接系统工程边。

但它并不是 Ascend / CANN 官方社区项目，也没有证据说明华南理工团队参与 CANN 核心治理，所以本页只记录硬件与系统集成关系。

## 开源边界

方案大量依托 openEuler 开源生态，但没有发现一个与该方案同名、由华南理工维护的公开代码仓库，因此 `open_source: false` 表示“方案本身没有已确认的独立开源仓库”，而不是说其底层组件全部闭源。
