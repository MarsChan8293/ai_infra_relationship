# 启元实验室（Qiyuan Lab）

启元实验室是北京智能科技领域的新型科研机构。清华大学科研院公开材料显示，清华大学与北京市联合筹建启元实验室；因此本图谱将其作为独立研究机构节点，并记录与清华大学的长期科研协作，不将其简单视为清华大学下属实验室。

## AI Infra 主线

启元实验室在 AI Infra 方向的重要抓手是面向国产智能芯片的软件栈统一。2025 年 CCF《计算》专题文章《面向国产智能芯片的统一智能计算架构》明确写明：启元实验室牵头提出“九源统一智能计算架构”，围绕统一算子库/通信库、运行时、领域编程语言和异构硬件适配建设基础软件层。

公开的九源 / InfiniTensor 生态目前覆盖：
- [[community/InfiniTensor/InfiniTensor|InfiniTensor]]：面向 GPU 与 AI accelerators 的高性能推理引擎 / 编译优化系统。
- InfiniCore：统一算子、通信与运行时底座。
- InfiniLM：大模型推理框架。
- InfiniTrain：大模型训练框架。
- NineToothed（九齿）：面向 AI 计算的领域编程语言。

InfiniTensor 官方 GitHub organization 明确写明该组织由 Qiyuan Lab、Tsinghua University 等支持；2026 年九源生态公开材料进一步将路线概括为“整体统一适配 + 单点极致优化”，目标是降低国产异构算力的软件迁移和 Token 成本。

## 关键人物

- [[company/趋境科技/武永卫 Yongwei Wu|武永卫（Yongwei Wu）]]：启元实验室智能计算系统研究中心主任、教授；研究方向包括并行与分布式处理、云计算和存储系统。
- [[university/启元实验室/王豪杰 Haojie Wang|王豪杰（Haojie Wang）]]：启元实验室智能计算系统研究中心 / 清华大学计算机系助理研究员；清华官方页面明确写明其主持 InfiniTensor 开发。
- [[university/启元实验室/潘泽众 Zezhong Pan|潘泽众（Zezhong Pan）]]：启元实验室工程师；研究方向为统一算子库、通信库和运行时。
- [[university/启元实验室/黄嘉成 Jiacheng Huang|黄嘉成（Jiacheng Huang）]]：启元实验室智能计算系统研究中心工程师；研究方向为人工智能领域编程语言。
- [[university/启元实验室/李映辉 Yinghui Li|李映辉（Yinghui Li）]]：启元实验室助理研究员；研究方向为智能计算系统、智能编译器和高性能计算。

## 与清华大学的关系

清华大学公开材料确认学校与北京市联合筹建启元实验室；同时，王豪杰、武永卫等研究人员在启元与清华之间形成明确的联合研究和人员网络。这里记录为科研合作 / 联合人员关系，不据此推断启元实验室的组织隶属。
