# Shi Qiu

Shi Qiu 是厦门大学计算机方向博士生、NICE Lab 成员，个人主页明确写明由 [[university/上海交通大学/张一鸣 Yiming Zhang|张一鸣（Yiming Zhang）]] 指导。研究兴趣集中在 virtualization、filesystem / storage、cloud storage 与 GPU storage。

## AI Infra / GPU Storage 主线

- [[university/厦门大学/GeminiFS|GeminiFS]]：FAST 2025 第一作者之一，GPU-centric companion file system。
- [[community/xPU-IO/Tutti/Tutti|Tutti]]：2026 论文第一作者；项目将 GPU-centric storage 继续推进到 SSD-backed KV cache / long-context LLM serving。
- Tutti 仓库中 GitHub 账号 `qq502233945` 直接提交了 vLLM KV connector baseline，因此这里可以建立“论文作者 + 直接工程贡献”双重项目关系，但不自动写成 formal maintainer。

## 导师 / 合作关系
