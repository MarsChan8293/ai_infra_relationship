# AI Infra Relationship

这是一个面向 Obsidian 的 AI Infrastructure 人才关系图谱。

## 组织方式

- 一级目录：公司 / 组织
- 二级文件：人物简历
- 人物之间使用 `[[双链]]` 关联
- 公司、学校、项目均使用 YAML frontmatter 标签，便于 Dataview / Graph View 检索

## 重点社区

- [[vLLM]]
- [[SGLang]]

## 使用建议

在 Obsidian 中开启 Graph View，并按 `company`、`project`、`school`、`role` 等 tag 过滤，可以观察公司、学校与开源社区之间的人才流动。
