# 梁文锋（Liang Wenfeng）

[[DeepSeek]] 创始人 / CEO，也是量化机构 High-Flyer（幻方量化）的联合创始人。

## 教育经历
- [[Zhejiang University]]：电子信息工程本科
- [[Zhejiang University]]：信息与通信工程硕士

## 工作与创业
- High-Flyer：联合创始人，使用机器学习与大规模计算基础设施做量化研究
- [[DeepSeek]]：2023 创立，转向基础模型研究

## 技术与组织关系
- [[DeepSeek-V3]] / [[DeepSeek-R1]]：作者名单中的 Wenfeng Liang / Wenfeng Liang
- High-Flyer 的计算基础设施与研究文化是 DeepSeek 的重要组织前史
- 与 [[陈德里]]、[[郭达雅]]、[[邵智宏]] 等形成“创始人 + 小型高密度研究团队”结构
