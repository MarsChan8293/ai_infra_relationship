# Hugging Face

## 公司简介
Hugging Face 是开放模型与机器学习工具生态公司，核心资产包括 Hub、Transformers、Datasets、Accelerate 与 inference tooling。它位于模型发布/分发、framework compatibility 与 production inference 之间，是开源模型生态的连接枢纽。
