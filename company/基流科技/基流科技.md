# 基流科技（InfraWaves）

## 公司简介
基流科技（InfraWaves）是面向大规模 AI 算力集群的基础设施公司，重点覆盖分布式计算通信、高速组网、集合通信、并行 / 调度、集群运行管理与大模型 workload orchestration。

2026 年香港上市申请材料显示，公司已把产品能力从“高速网络 + 集群交付”继续延伸到 AI computing operating system、post-training 与 inference task management。公司 2026 年 2 月完成注册地址与公司名称调整，申请材料使用“上海基流科技股份有限公司 / Infrawaves Co., Ltd.”。

## AI Infra 位置
- 大规模 GPU / AI 集群基础设施
- 高速无损网络与 GPU-RDMA 通信
- 集合通信与多厂商异构通信
- 拓扑感知调度、容错与集群管控
- post-training / inference resource orchestration
- MoE serving 与 expert disaggregation 研究
- 智算集群设计、部署、调优与运维

## 核心产品 / 项目

### [[company/基流科技/Venus|Venus]]
AI 算力操作系统 / 集群运行管理平台。覆盖 scheduling、communication、cache、isolation、monitoring、fault diagnosis、recovery 与 workload acceleration。公开材料明确披露 inference task management、distributed inference、multi-replica throughput scaling 和 elastic inference scaling；VenusRL / VenusBox 继续进入 RL / post-training workflow。

### Mercury
AI 算力网络系统，覆盖 MercuryNOS、自研交换机、光模块与 RDMA NIC。MercuryNOS 提供动态流量均衡、拥塞管理与毫秒级网络监控，是公司“network system → cluster performance”主线。

### [[community/sii-research/VCCL/VCCL|VCCL]]
与 Shanghai Innovation Institute（SII）共同支持的开源 GPU collective communication library，面向大规模训练集群提供高效率、高可用与高可观测通信能力。

### [[company/基流科技/HetCCL|HetCCL]]
与北京大学、BAAI、ICT 等研究者共同推进的 mixed-vendor heterogeneous collective communication 系统，将基流通信能力从同构 GPU 集群扩展到多厂商异构算力。

### [[company/基流科技/Expert-as-a-Service|Expert-as-a-Service（EaaS）]]
面向大规模 MoE inference serving 的系统研究。胡效赫、Yanmin Jia、Yan Zhang、He Liu、Mingjun Zhang 以 Infrawaves affiliation 共同参与，把 CPU-free P2P communication 与 expert disaggregation、elastic serving、fault tolerance 连接起来。

## 推理优化主线
此前基流节点最强的公开证据主要集中在 VCCL / HetCCL，因此图谱容易把公司停留在“网络和训练集群”层。

本轮补全后，可以建立更直接的推理链路：

[[company/基流科技/Venus|Venus]] inference scheduling
←→ cluster scheduler / runtime
←→ [[community/sii-research/VCCL/VCCL|VCCL]] / [[company/基流科技/HetCCL|HetCCL]] communication substrate
→ [[company/基流科技/Expert-as-a-Service|EaaS]] CPU-free P2P + expert disaggregation
→ large-scale MoE serving

这是目前基流科技与“推理优化人才 / 系统”最值得继续 BFS 的方向。
