# 腾讯（Tencent）

腾讯在本图谱中主要通过 AI Infra / LLM serving 工程人员与开源系统形成连接。本节点只记录可公开核验的人才与技术关系，不因为员工参与某个开源项目就自动推断腾讯对该项目拥有组织级治理或所有权。

## 直接 AI Infra 项目
- [[community/Tencent/HPC-Ops/HPC-Ops|HPC-Ops]]：腾讯混元 AI Infra 团队直接开发的 production-grade LLM inference operator library。官方仓库明确将其用于腾讯大规模生产推理，并覆盖 Attention、MoE、GEMM、sampling 与通信计算融合，因此这是可确认的公司级项目关系。

## LMCache 人才连接
- [[company/腾讯/Baolong Mao|Baolong Mao]]：LMCache Committer；官方 MAINTAINERS 将其 affiliation 标为 Tencent，当前 CODEOWNERS 覆盖 cache controller、distributed/L2、platform、storage backend、vLLM integration 等路径。
- [[company/腾讯/Chunxiao Zheng|Chunxiao Zheng]]：LMCache Committer；官方 MAINTAINERS 将其 affiliation 标为 Tencent，当前 CODEOWNERS 覆盖 cache controller、distributed/L2、memory management 与 storage backend 等路径。

2026-01 LMCache 官方 P2P 文章明确记录 Tencent 与 LMCache 团队共同实现 production-grade multi-node CPU P2P KV sharing，其中 Baolong Mao、Chunxiao Zheng 作为 Tencent 作者出现。这里据此确认人物 affiliation 与联合工程工作，但不升级为 Tencent → LMCache 的公司级治理边。
