# Alibaba Cloud

## 公司简介
Alibaba Cloud 是阿里巴巴的云计算与 AI 基础设施平台，覆盖计算、存储、网络、容器、AI 平台与大模型服务。与 AI Infra 图谱最直接的关系来自 Qwen/通义模型生态、大规模云上训练与推理，以及面向企业的模型部署能力。

## 图谱中的连接
[[Qwen]] 是 Alibaba/Alibaba Cloud 基础模型谱系的核心节点；云上 serving 又与 [[vLLM]]、Kubernetes、异构加速器和 EP communication 等系统生态发生连接。[[Mooncake]] 的生态中也可观察到阿里云等云厂商参与，但项目兼容或联合生态不自动推出人物直接合作。
