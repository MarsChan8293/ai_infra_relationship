# PPIO

## 公司简介
PPIO 是独立 AI / Agentic Cloud 服务商，提供 GPU 云、Serverless GPU、模型 API、推理加速、Agent 沙箱与分布式算力服务。公司由姚欣与王闻宇于 2018 年联合创立，并持续从分布式云向 AI 原生基础设施演进。

## AI Infra 位置
- GPU Cloud 与 Serverless GPU
- 大模型 / 多模态模型 API
- 推理加速与异构算力调度
- Agent sandbox / Agentic Cloud
- 分布式算力资源整合与弹性调度

## 图谱中的连接
PPIO 公开强调与 [[vLLM]]、[[SGLang]]、Hugging Face 等开源生态协作，因此适合作为“开源 inference engine → 商业 AI cloud / Agentic Cloud”的平台节点。生态合作本身不自动推断为人物直接协作。
