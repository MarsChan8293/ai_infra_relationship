# 国产化人工智能算力平台异构并行加速项目

该项目由 [[company/爱特思/深圳爱特思信息技术有限公司|深圳爱特思信息技术有限公司]] 在 2025 年琶洲实验室成果路演中公开展示，目标是解决国产 AI 算力从“可用”走向“好用”的底层性能问题。

## AI Infra 位置

项目位于 AI stack 的使能层：

**国产 AI 加速器 → kernel / operator 优化 → runtime / application migration → 大模型训练与推理**

公开介绍强调，通过底层算子库和优化技术提升计算单元与内存带宽利用率，使大模型在国产硬件上更高效、稳定地训练和推理。

## Ascend 路线

项目介绍本身面向“各类国产 AI 加速设备”，不是单一 Ascend 项目。

但深圳爱特思的公开专利组合已经包含：

- 基于昇腾 910 的复数矩阵向量乘法；
- Ascend Atlas 矩阵计算单元相关优化；
- 面向深度学习加速器 matrix core 的高性能 GEMV。

因此本项目与 Ascend 的关系有 operator-level 技术证据，但本页不把整个项目硬限定为 Ascend-only。
