# 派欧云

## 公司简介
派欧云是独立 AI / Agentic Cloud 服务商，提供 GPU 云、Serverless GPU、模型 API、推理加速、Agent 沙箱与分布式算力服务。公司由姚欣与王闻宇于 2018 年联合创立，并持续从分布式云向 AI 原生基础设施演进。

## AI Infra 位置
- GPU Cloud 与 Serverless GPU
- 大模型 / 多模态模型 API
- 推理加速与异构算力调度
- Agent sandbox / Agentic Cloud
- 分布式算力资源整合与弹性调度

- [[company/派欧云/王闻宇 Wayne Wang|王闻宇（Wayne Wang）]] — 联合创始人、CTO；PPTV 首席架构师、分布式系统背景
