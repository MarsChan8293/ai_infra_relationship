# Ion Stoica

当前：[[university/UC Berkeley/UC Berkeley|UC Berkeley]] EECS Professor、[[university/UC Berkeley/Sky Computing Lab|Sky Computing Lab]] Director；[[company/Anyscale/Anyscale|Anyscale]] co-founder / Executive Chairman、[[company/Databricks/Databricks|Databricks]] co-founder / Executive Chairman，以及 [[company/Inferact/Inferact|Inferact]] founding member。

## AI Infra 位置
Ion Stoica 是 Berkeley systems → AI infrastructure 网络中最重要的跨代节点之一。其学术、开源与创业谱系至少连续出现三轮：

`AMPLab → Spark → Databricks`

`RISELab → Ray → Anyscale`

`Sky Computing Lab → vLLM / SGLang / Jenga / agent systems → Inferact`

因此他在本图谱中的意义不只是某个 serving 项目的导师，而是反复把 distributed systems 研究转化为开源基础设施与产业组织的桥节点。

## 第一代：Spark / Databricks
- [[university/UC Berkeley/Matei Zaharia|Matei Zaharia]]：正式博士学生，Spark 原始创建者，后共同创办 Databricks。
- [[university/UC Berkeley/Reynold Xin|Reynold Xin]]：正式博士学生，distributed dataflow / Spark 技术谱系，后共同创办 Databricks。
- [[community/apache/Spark/Spark|Apache Spark]]：Berkeley AMPLab 最典型的研究开源化成果之一。

## 第二代：Ray / Anyscale
- [[university/UC Berkeley/Philipp Moritz|Philipp Moritz]]：正式博士学生，博士论文即 Ray distributed execution engine；后共同创办 Anyscale。
- [[university/UC Berkeley/Robert Nishihara|Robert Nishihara]]：Ray creator / Anyscale co-founder；其正式博士导师是 Michael Jordan，因此 Ion ↔ Robert 只建共同研究 / 开源 / 创业强边，不伪造 advisor/student。
- [[community/ray-project/Ray/Ray|Ray]]：从 distributed ML execution engine 演化为现代 AI workloads 的通用分布式运行基础设施。

## 第三代：Sky / inference / agents
- [[Inferact/Woosuk Kwon|Woosuk Kwon]]、[[community/vllm-project/vLLM/李卓翰 Zhuohan Li|Zhuohan Li]]、[[community/vllm-project/vLLM/Simon Mo|Simon Mo]]：vLLM / inference serving 学生谱系。
