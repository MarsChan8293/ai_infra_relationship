# GPUStack

GPUStack 公司 / 团队节点围绕同名开源项目 [[community/gpustack/GPUStack/GPUStack|GPUStack]] 构建企业级 AI infrastructure，核心位置是把异构 GPU/NPU 资源转换为可管理、可观测、可调度的 production model serving 能力。

## AI Infra 方向
- 多集群 GPU/NPU 管理与资源编排
- vLLM / SGLang / TensorRT-LLM 等推理引擎统一管理
- MaaS / GPUaaS、模型网关、高可用和可观测性
- 国产异构加速器适配与 Token factory 场景
