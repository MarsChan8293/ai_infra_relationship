# 燧原科技

燧原科技（Enflame Technology）在本图谱中的价值不只来自 AI accelerator 硬件本身，更重要的是它与 [[上海交通大学]] 形成了一条可验证的 **compiler / kernel engineering** 研究与开源网络。

## LANCER Lab / Croqtile

[[university/上海交通大学/LANCER Lab|LANCER Lab]] 的官方 GitHub 组织页明确将其定义为 **Shanghai Enflame Technology 与 Shanghai Jiao Tong University 的联合实验室**。

[[Croqtile]] 是这条线目前最直接的开源软件节点。项目近期提交记录里，来自燧原 compiler 研究网络的工程贡献非常集中，尤其是 [[Xiaofeng Guan]] / Garfee Guan 与 [[Enming Fan]]。

因此 `projects: [Croqtile]` 表示的是有联合实验室起源与持续核心工程贡献支撑的强关系，不是因为“某位员工偶尔提交过代码”而自动推断出的公司关系。

## 研究连续性

这条技术线并不是突然从 Croqtile 开始：

- **PresCount（CGO 2024）**：register allocation / register bank conflict reduction；
- **Postiz（CGO 2025）**：post-increment addressing / loop optimization；
- **Samoyeds（EuroSys 2025）**：MoE structured sparsity / Sparse Tensor Cores；
- **SPIDER（PPoPP 2026）**：Sparse Tensor Core for stencil computation；
- **Croqtile（2026）**：把 tile / warp / pipeline / symbolic verification 组织成 agent-friendly kernel DSL。

从图谱视角看，这形成了一条从传统 compiler backend optimization，逐步走向 AI kernel DSL 与 agent-driven kernel engineering 的连续脉络。
