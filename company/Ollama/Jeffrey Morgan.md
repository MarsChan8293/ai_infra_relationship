# Jeffrey Morgan

Ollama Co-founder，也是 [[community/ollama/Ollama/Ollama|Ollama]] 开源项目的核心创建者之一。

## 创业 / 工程路径

Ollama 2026-07 官方文章由 Jeff 与 Michael 联署，回顾两人在大学时期共同创建 Kitematic；Kitematic 2015 年被 Docker 收购，之后相关工作发展为 Docker Desktop。两人此后再次共同创建 Ollama，目标是把 open models 变成开发者可以直接安装、运行和集成的软件。

## Ollama / inference

公开 GitHub commit 记录显示 Jeffrey 持续参与 Ollama runtime、model support、cloud/local policy、Vulkan / GGML / llama.cpp compatibility 等工程讨论和代码修改。其公开 commit 主要使用 Gmail，因此不把个人邮箱写入 `public_email`，也不使用邮箱域名推断组织。
