# Anyscale

## 公司简介
Anyscale 是围绕 Ray 商业化与云上分布式 AI workload 建立的平台公司，由 Ray/UC Berkeley systems 网络孕育。它覆盖 distributed computing、training、data processing 与 model serving，是“学术系统项目 → 开源社区 → 商业平台”的典型 Berkeley 路径。

## 主要贡献的社区项目
- [[community/ray-project/Ray-Serve/Ray-Serve|Ray Serve]]：Ray 的核心 commercial / maintainer ecosystem 公司节点；该关系不等于所有 Ray contributor 都属于 Anyscale。

## 图谱中的连接
[[community/ray-project/Ray-Serve/Ray-Serve|Ray Serve]] 是最直接的 serving 节点；[[Simon Mo]] 等人物把 Ray Serve 的 production serving 经验进一步连接到 [[vLLM]]。Anyscale 与 UC Berkeley / Ray 的历史关系是组织与项目谱系，不代表所有 Ray contributor 都是 Anyscale 员工。
