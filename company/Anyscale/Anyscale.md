# Anyscale

## 公司简介
Anyscale 是围绕 [[community/ray-project/Ray/Ray|Ray]] 商业化与云上分布式 AI workload 建立的平台公司，是 UC Berkeley RISELab “research system → open source → company” 路线的代表性节点。

公开创始资料明确列出 Ray creators [[university/UC Berkeley/Robert Nishihara|Robert Nishihara]]、[[university/UC Berkeley/Philipp Moritz|Philipp Moritz]]、[[company/Inferact/Ion Stoica|Ion Stoica]] 与 Michael Jordan 的创始网络。

## Berkeley systems 谱系
`UC Berkeley / RISELab → Ray → Anyscale`

- Philipp Moritz：Ion Stoica / Michael Jordan 正式博士学生，博士论文主题即 Ray distributed execution engine。
- Robert Nishihara：正式博士导师是 Michael Jordan；与 Ion 的强关系是 Ray research / open-source collaboration + Anyscale cofounder，而非 advisor/student。
- Ion Stoica：co-founder / Executive Chairman，把 Berkeley distributed systems 研究继续推向生产 AI platform。

## Serving 生态
- [[community/ray-project/Ray-Serve/Ray-Serve|Ray Serve]]：Anyscale 最直接的 model serving / production AI infrastructure 节点。
- Simon Mo 等 Berkeley / Anyscale 研究与工程网络又把 Ray Serve 的 serving 经验连接到 vLLM / Inferact。

## Nscale 交易状态
2026-07-30，Anyscale 与 Nscale 宣布签署收购的 definitive agreement。公开公告明确说明交易仍受 closing conditions 与 regulatory approvals 约束，预计 2026 年下半年完成。截至 2026-09-17 未找到正式 closing 公告，因此本图谱只记录“待交割收购协议”，不把 Anyscale 人员自动改写为 Nscale 当前员工。
