# 杭州先进编译科技有限公司

## 公司定位
杭州先进编译科技有限公司聚焦 AI 基础软件、编译优化、异构算力适配与大模型推理优化。2026 年 CCF CNCC 公开资料直接将 [[柴赟达]] 标注为“杭州先进编译科技有限公司先进编译实验室基础编译部部长”。

公开会议资料同时将 [[李嘉楠]] 标注为“先进编译 CTO”，其工作聚焦 AI 基础软件、异构算力适配、高性能算子和大模型推理产品研发。

## 先进编译实验室
[[先进编译实验室]]是公司体系下的重要研发团队/技术品牌，公开方向覆盖 LLVM / MLIR / Triton / Triton-Shared、AI compiler、国产 GPU/NPU 适配、高性能算子、程序性能优化与大模型推理优化。

## 与开源生态的关系
- [[community/flagos-ai/FlagTree/FlagTree|FlagTree]]：[[李嘉楠]]是公开确认的核心开发贡献者；[[柴赟达]]公开报告聚焦 Triton-TLE 与国产平台适配。
- [[community/flagos-ai/FlagGems/FlagGems|FlagGems]]：AdvancedCompiler GitHub 账号长期以 collaborator 身份向上游提交算子与推理相关 PR，但 FlagGems 的治理仍属于 FlagOS 社区，不能写成公司 owned project。
