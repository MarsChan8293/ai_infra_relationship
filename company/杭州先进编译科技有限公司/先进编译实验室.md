# 先进编译实验室

先进编译实验室长期公开研究方向包括高性能计算、编译技术、程序优化和国产自主可控。其 GitHub 入口 AdvancedCompiler/AdvancedCompiler 主要承载《程序性能优化理论与方法》《深度学习编译器设计》等课程、教材、代码和教学资料，因此本图谱将它建模为研发团队/实验室节点，而不是把该仓库误当成一个 AI Infra 项目。

## 人物主干
- [[柴赟达]]：2026 CCF 公开资料确认其为先进编译实验室基础编译部部长，方向覆盖 AI compiler、LLVM/MLIR、Triton/Triton-Shared 与国产 GPU/NPU 编译适配。
- [[李嘉楠]]：2025 FlagOS 技术文章明确写为先进编译实验室成员、FlagTree 核心开发贡献者；2026 公开会议资料进一步列为“先进编译 CTO”。
- [[韩林]]、[[高伟]]、[[李嘉楠]]：清华大学出版社《深度学习编译器设计》作者简介明确列为先进编译实验室成员。

## 技术主线
### FlagTree / TLE
[[community/flagos-ai/FlagTree/FlagTree|FlagTree]] 是实验室当前最重要的外部开源连接之一。[[李嘉楠]]负责过 GPGPU 场景的 FlagTree 编译优化实践；[[柴赟达]]公开报告介绍 Triton-TLE 在国产平台的适配优化。

TLE 当前可按三个抽象层理解：TLE-Lite、TLE-Struct、TLE-Raw，目标是在可移植性、结构化优化信息和硬件细粒度控制之间分层取舍。

### FlagGems
AdvancedCompiler GitHub 账号是 [[community/flagos-ai/FlagGems/FlagGems|FlagGems]] 的长期工程 contributor / collaborator，提交覆盖 FlashAttention、paged MQA、W8A8/FP8、vLLM RMSNorm patch、TopK、TLE operators 等。

这里记录技术贡献关系，不把实验室写成 FlagGems 的治理方。

## 学术 / 工程谱系
[[韩林]]、[[高伟]]、[[李嘉楠]]的公开论文网络长期覆盖 HPC、自动向量化、TVM operator fusion、深度学习编译器量化等方向，形成：

HPC / LLVM / SIMD → deep-learning compiler → Triton / FlagTree / TLE → 多芯 AI compiler / kernel / inference
