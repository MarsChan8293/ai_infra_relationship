# 李嘉楠（Jianan Li）

先进编译 AI compiler / heterogeneous computing 主线的关键人物。

## 当前公开角色
- 2025 FlagOS 技术文章明确写明：李嘉楠来自[[先进编译实验室]]，是 [[community/flagos-ai/FlagTree/FlagTree|FlagTree]] 核心开发贡献者。
- 2026 全球 AI 芯片峰会公开资料将其列为“先进编译 CTO”，主要负责 AI 基础软件、异构算力适配及大模型推理产品研发。

由于“先进编译 CTO”的会议资料使用的是品牌简称，本页把当前 affiliation 稳健落到“先进编译实验室”，不单凭简称反推法定公司任职。

## 技术主线
其公开工作从 LLVM / HPC 延伸到 Triton / FlagTree / 高性能算子 / LLM inference：

HPC / LLVM → deep-learning compiler → Triton / FlagTree → heterogeneous accelerator → LLM inference

## 与韩林 / 高伟
[[韩林]]、[[高伟]]、李嘉楠共同编著《深度学习编译器设计》，公开论文网络还覆盖 TVM operator fusion、multi-granularity quantization 等。
