# Baseten

## 公司简介
Baseten 是面向生产环境的 AI model inference 平台公司，关注模型打包、部署、autoscaling、GPU resource management 与低延迟 serving。它处在开源 engine/kernel 与最终应用之间，核心价值是把复杂的模型运行栈产品化。

## 人才关系
- [[community/sgl-project/SGLang/Yineng Zhang|Yineng Zhang]]：公开报道在其加入 [[Together AI]] 前曾列为 Baseten **Lead Software Engineer**；其个人主页确认 2025-07 加入 Together AI。Baseten 任职的精确开始月份公开资料未确认，因此不补猜测区间。其 2024–2025 同期又是 [[SGLang]] core maintainer，形成 production inference platform ↔ open-source serving engine 的人才桥。

## 图谱中的连接
Baseten 与 [[vLLM]]、TensorRT、CUDA 等推理生态存在直接技术集成，同时其开源 Truss 等工具连接模型 packaging 与 production deployment。项目集成不等于开源项目核心维护关系，人物边需独立核验。
