# DeepSeek-R1

## 项目简介
DeepSeek-R1 是 DeepSeek 的 reasoning 模型路线，核心特色是用 reinforcement learning 强化长链条推理能力，并公开技术报告、模型信息与相关资源。它把 reasoning / RL 与模型 serving、长输出 workload 和高效推理系统连接起来。
