# 深度求索

## 公司简介
深度求索是中国 frontier-model lab，以高效训练、MoE、reasoning 与系统协同著称。它在 AI Infra 图谱中的特殊之处，是把模型创新持续下沉为独立开源系统组件，包括 EP communication、GEMM/attention kernels、分布式存储、xPU JIT 与 speculative decoding，并通过产学合作继续推进 agentic inference 的 KV-cache / storage 路线。

## 主要贡献的社区项目
- [[community/deepseek-ai/DeepSeek-Infra/DeepSeek-Infra|深度求索 Infra]]：公司对外开源的 systems stack 集合。
- [[community/deepseek-ai/DeepSeek-Infra/DeepEP|DeepEP]]：MoE expert-parallel communication。
- [[community/deepseek-ai/DeepSeek-Infra/DeepGEMM|DeepGEMM]]：GEMM / MoE GPU kernels。
- [[community/deepseek-ai/DeepSeek-Infra/FlashMLA|FlashMLA]]：MLA / attention kernels。
- [[community/deepseek-ai/DeepSeek-Infra/3FS|3FS]]：distributed storage。
- [[community/deepseek-ai/DeepSeek-Infra/DeepJIT|DeepJIT]]：xPU kernel JIT/runtime。
- [[community/deepseek-ai/DeepSpec/DeepSpec|DeepSpec]]：deepseek-ai 公开维护的 speculative decoding 全栈代码库，当前包括 DSpark、DFlash、Eagle3 等 draft-model 路线。
- [[community/deepseek-ai/DualPath/DualPath|DualPath]]：SIGCOMM 2026 agentic LLM inference / disaggregated KV-cache storage I/O 产学合作项目，作者网络横跨 DeepSeek-AI、清华与北大。

其中 DeepSeek-Infra / DeepSpec 属于明确的 **company-led / deepseek-ai maintained** 关系；DualPath 则按公开作者单位建模为 industry-academia research collaboration。具体人物责任仍按各仓库、论文公开作者与 affiliation 分别建边。
