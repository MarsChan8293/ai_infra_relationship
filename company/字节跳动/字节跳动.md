# 字节跳动

## 公司简介
字节跳动是同时拥有大规模推荐系统、云计算和 foundation-model 研发能力的互联网公司。其 AI Infra 优势来自超大规模 GPU 集群、训练/推理系统、模型 serving、编译与异构计算等工程场景，是中国 AI systems 人才的重要产业汇聚点。

## 主要贡献的社区项目
- [[community/AIBrix/AIBrix|AIBrix]]：**原始开发 / 发起 / 生产落地**。AIBrix 后续进入 vLLM Project 社区治理，因此这条边表示 字节跳动 是 originator / primary company contributor，而不是当前项目“归 字节跳动 所有”。

## AI Infra 人物桥
- [[company/字节跳动/方佳瑞 Jiarui Fang|方佳瑞（Jiarui Fang）]] — 当前 字节跳动 Software Engineer / AI infra team lead network；前 [[潞晨科技]] CTO、[[Colossal-AI]] lead，公开方向覆盖 LLM / DiT training、inference、RL、veMLP 与 Volcano Ark MaaS。

## 图谱中的连接
与 [[vLLM]]、[[SGLang]]、[[LightLLM]]、[[Colossal-AI]]、Kubernetes/GPU kernel 等开源技术存在广泛生态交叉。方佳瑞提供了一条有公开履历支持的 `Colossal-AI / HPC-AI → 字节跳动 AI infra` 人才迁移边；其他普通开源贡献者仍不自动标记为 字节跳动 员工或直接协作者。
