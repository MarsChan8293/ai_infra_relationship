# Databricks

## 公司简介
Databricks 从 UC Berkeley AMPLab / [[community/apache/Spark/Spark|Apache Spark]] 谱系发展为 Lakehouse 与 data + AI 平台公司，是 Berkeley systems 第一代“研究 → 开源 → 商业基础设施”主干。

## Berkeley systems 谱系
`UC Berkeley / AMPLab → Spark → Databricks`

- [[university/UC Berkeley/Matei Zaharia|Matei Zaharia]]：Spark 原始创建者，Ion Stoica / Scott Shenker 正式博士学生；当前 Databricks CTO / Chief Technologist 网络。
- [[university/UC Berkeley/Reynold Xin|Reynold Xin]]：Ion Stoica / Michael Franklin 正式博士学生；Databricks co-founder / Chief Architect。
- [[company/Inferact/Ion Stoica|Ion Stoica]]：Databricks co-founder / Executive Chairman，同时又继续领导 Berkeley Sky，使早期 Spark / data systems 与现代 AI systems 形成跨代连接。

## 与现代 AI Infra 的连接
Databricks 当前已经从 Spark / data processing 扩展到训练、模型治理、Mosaic AI 等 AI platform 场景。仓库中的 [[community/ai-dynamo/NIXL/NIXL|NIXL]] 等 inference data-movement 生态可在应用层与 Databricks AI platform 发生连接，但不因此推断 Databricks 是这些开源项目的治理方。

更重要的长期图谱关系是：
`Spark / Databricks → Matei Zaharia / Ion Stoica → Sky Computing Lab → modern inference / agent systems`。
