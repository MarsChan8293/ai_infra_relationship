# 智谱

## 公司简介
智谱是中国 frontier-model company，技术谱系与清华大学 KEG / GLM 研究网络高度相关。从 GLM、GLM-130B、ChatGLM 延伸到 Agentic、Reasoning 与 Coding 模型，它是“清华模型研究 → 商业 foundation-model lab”的典型产业化节点。
