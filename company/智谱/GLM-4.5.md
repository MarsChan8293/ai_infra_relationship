# GLM-4.5

## 项目简介
GLM-4.5 是智谱 / Z.ai 的 Agentic、Reasoning、Coding（ARC）foundation model 系列，延续清华 KEG / GLM 技术谱系，并把 reasoning、coding 与 agent workload 汇入同一模型路线。

## GitHub
https://github.com/zai-org/GLM-4.5

## 主要维护者 / 组织
由 [[智谱]] / zai-org 公开维护。当前 canonical GitHub 组织为 `zai-org`，用于与早期 THUDM / ChatGLM 时代的组织命名区分。
