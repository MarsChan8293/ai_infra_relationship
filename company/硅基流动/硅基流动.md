# 硅基流动

## 公司简介
硅基流动是面向大模型与多模态模型的 AI inference infrastructure 公司，核心定位逐步从模型 API / MaaS 延伸为面向大规模 Token 生产的“Token 供应平台”。其技术价值主要在于推理引擎、调度、KV Cache、异构算力与生产级模型服务，而不是自研基础模型或芯片。

## AI Infra 位置
- [[community/siliconflow/SiliconLLM/SiliconLLM|SiliconLLM]]：公司自研高性能 LLM inference engine，覆盖模型执行、算子、并行、PD 分离与异构硬件适配。
- [[community/siliconflow/OneDiff/OneDiff|OneDiff]]：开源 diffusion inference acceleration / compiler 项目，连接 OneFlow、Nexfort、GPU kernel 与多模态生成推理。
- Token 供应平台：面向多模型并发、弹性扩缩、智能路由与生产级 SLA。
- KV Cache：公开架构包含跨集群 distributed Prefix Cache 感知路由与 KV Cache 分级优化。
- 异构算力：公开方案覆盖 NVIDIA、昇腾、沐曦、摩尔线程等多种硬件后端。

## 推理技术主线
`OneFlow / CUDA kernel → 硅基流动 → SiliconLLM → PD separation / KV Cache / routing / scheduler → Token serving`

2026 年硅基流动公开的 Token 供应平台架构中，网关会基于业务流量特征进行智能路由，并针对 KV Cache 使用分布式 Prefix Cache 感知策略；算力调度引擎负责模型实例的弹性扩缩容与资源利用率优化。

## 国产异构算力桥
2026 年硅基流动与摩尔线程公开了生产级 PD 分离异构混部方案：摩尔线程 MTT S5000 负责 Prefill，另一类高带宽 GPU 负责 Decode，通过 [[Mooncake]] RDMA 进行 KV Cache 跨芯片传输；硅基流动推理引擎提供统一模型加载、执行和调度接口，摩尔线程 [[MATE]] 提供算子优化。

这条线在图谱中形成：
`SiliconLLM → PD disaggregation → Mooncake / KV transfer → MUSA / MATE → heterogeneous serving`
