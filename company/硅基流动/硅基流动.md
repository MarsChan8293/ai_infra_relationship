# 硅基流动

## 公司简介
硅基流动是面向大模型与多模态模型的 AI inference infrastructure 公司，提供 Serverless / dedicated inference、模型 API、微调与私有化部署等服务。其图谱价值主要在于连接模型服务、推理优化、异构算力与开发者平台，而不是自研基础模型或芯片。

## AI Infra 位置
- 高吞吐、低延迟模型推理与 serving
- Serverless / 专属实例与模型 API
- 异构算力与模型部署
- 面向 Agent、RAG、代码、多模态等 workload 的 Token 服务

## BFS 主线
OneFlow → [[袁进辉 Jinhui Yuan|袁进辉]] / [[柳俊丞 Juncheng Liu|柳俊丞]] / [[赵震 Zhao Zhen|赵震]] → 硅基流动→ SiliconLLM / OneDiff / Token serving / 异构算力适配。

## 图谱中的连接
与 [[vLLM]]、[[SGLang]] 等开源 inference engine，以及 [[深度求索]]、[[Qwen]]、[[月之暗面]] 等模型生态存在技术上下游关系；模型兼容或平台支持不自动推断为人物直接协作。
