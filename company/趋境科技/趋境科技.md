# 趋境科技

## 公司简介
趋境科技聚焦大模型系统与推理基础设施，承接清华系统研究、KTransformers / Mooncake 等开源技术积累，重点推进异构推理、KV cache、以存换算与高效 Token 生产服务。

## 主要贡献的社区项目
- [[community/kvcache-ai/KTransformers/KTransformers|KTransformers]]：公司当前人才网络与 KTransformers maintainer / 清华 MADSys 技术谱系直接重叠，是最清晰的产业核心贡献项目。
- [[community/kvcache-ai/Mooncake/Mooncake|Mooncake]]：趋境官网已把 Mooncake 与 KTransformers 并列放入“开源社区”，并明确写“依托 KTransformers 与 Mooncake 两大开源社区”；北京市经信局 2026-07 调研材料也明确写公司“参与 Mooncake 等开源项目的生态协作”。因此这里升级为组织级显式项目关系，但仍不改写 Mooncake 的历史起源：Moonshot AI + 清华 MADSys 是原始系统/论文/生产共研主线，趋境是后续核心共建、维护与商业化生态方之一。
