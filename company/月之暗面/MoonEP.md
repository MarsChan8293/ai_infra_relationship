# MoonEP

## 项目简介
MoonEP 是 Moonshot AI 的 Expert Parallel communication library，通过 dynamic redundant experts 等机制改善 MoE token load 在 ranks 之间的不均衡，服务于大规模 MoE 模型的训练/推理通信效率。

## GitHub
https://github.com/MoonshotAI/MoonEP
