# RadixArk

## 公司简介
RadixArk 是围绕高性能 LLM serving 与 [[SGLang]] 生态形成的 AI infrastructure 公司/团队节点。其人员网络与 SGLang 社区高度重叠，重点方向包括 runtime、GPU kernels、speculative decoding、多模态/生成模型 serving、模型优化与 release engineering。

## 主要贡献的社区项目
- [[community/sgl-project/SGLang/SGLang|SGLang]]：公司人物网络与项目 core maintainer / runtime / kernel / release engineering 高度重叠，是最强的产业核心贡献边；SGLang 仍保持社区治理。
