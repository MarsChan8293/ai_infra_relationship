# 华为

## 公司简介
华为在本图谱中的 AI Infra 主线聚焦 Ascend NPU、CANN kernel/toolchain、MindIE inference runtime/control plane 与模型压缩量化工具链。这里把“硬件生态贡献”和“公司主导项目”分开标注，避免把 vLLM-Ascend 这类社区项目误写成 华为 私有项目。

## 主要贡献的社区项目
- [[community/vllm-project/vLLM-Ascend/vLLM-Ascend|vLLM-Ascend]]：**hardware ecosystem core contributor**，项目仍由 vLLM Project / vLLM-Ascend 社区治理。
- [[community/Ascend/MindIE-LLM/MindIE-LLM|MindIE-LLM]]：**company-led** Ascend LLM inference runtime。
- [[community/Ascend/MindIE-Motor/MindIE-Motor|MindIE-Motor]]：**company-led** distributed serving / control plane。
- [[community/Ascend/MindIE-SD/MindIE-SD|MindIE-SD]]：**company-led** inference component / MoE-dispatch / communication path。
- [[community/Ascend/msModelSlim/msModelSlim|msModelSlim]]：**company-led** model compression / quantization toolchain。
- [[community/Ascend/ops-transformer/ops-transformer|ops-transformer]]：**company-led** CANN Transformer / LLM kernel library。
- [[community/Project-HAMi/HAMi/HAMi|HAMi]]：通过 华为 Cloud / Ascend 参与跨公司异构设备生态贡献，不是主导所有权关系。

## 图谱中的连接
[[vLLM]] · [[DeepJIT]] · Ascend/CANN · MindIE · Kubernetes/HAMi。Ascend 线的价值在于把 kernel、quantization、runtime、distributed serving 与上层开源 engine 串成一条完整 NPU inference optimization 链。
