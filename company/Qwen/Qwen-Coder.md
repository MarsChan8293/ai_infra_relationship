# Qwen-Coder

## 项目简介
Qwen-Coder 是 Qwen 的代码模型与 coding-agent 技术线。当前公开主线已发展到 Qwen3-Coder，面向代码生成、软件工程任务与 agentic coding，并与通用 Qwen3 模型共享模型与 serving 生态。

## GitHub
https://github.com/QwenLM/Qwen3-Coder

## 主要维护者 / 组织
由 [[Qwen]] / QwenLM 组织公开维护。仓库名称随模型代际演进，因此本图谱使用 Qwen-Coder 作为技术谱系节点、Qwen3-Coder 作为当前明确的公开仓库。
