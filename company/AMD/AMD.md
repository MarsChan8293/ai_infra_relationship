# AMD

## 公司简介
AMD 是 CPU、GPU 与数据中心加速器厂商。其 Instinct GPU 与 ROCm 软件栈构成 CUDA 之外最重要的开放 GPU compute 路线之一，因此在 AI Infra 图谱中主要承担硬件、kernel、collective communication 与推理框架适配这一层角色。

## 图谱中的连接
[[vLLM]]、[[llm-d]]、[[NIXL]] 等项目都需要处理 AMD/ROCm 或跨硬件生态适配。这里记录的是软硬件生态连接，不把“支持 AMD”自动等同于 AMD 员工直接参与项目。
