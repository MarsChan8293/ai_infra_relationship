# 方佳瑞（Jiarui Fang）

当前：[[ByteDance]] Software Engineer，公开个人资料显示其带领团队从事 LLM / DiT training、inference、RL 与 MaaS 基础设施；此前任 [[HPC-AI Tech]] CTO，并领导 [[Colossal-AI]]。

## 工作经历
- [[HPC-AI Tech]]：CTO，2022-02–2023-03；负责 Colossal-AI 等大规模训练系统。
- LightYear AI：2023 年后参与大模型创业网络。
- [[ByteDance]]：当前从事 AI infrastructure，方向覆盖训练、推理、RL、veMLP，以及 Volcano Ark 的模型服务系统。
