# Qwen3

## 项目简介
Qwen3 是 Qwen / Alibaba Cloud 的大语言模型系列，覆盖 dense 与 MoE 架构，并把 thinking / non-thinking 两种使用模式纳入统一模型家族。它连接 reasoning、multilingual、MoE 模型研发与开放 serving 生态，是 Qwen 人才网络的核心模型节点。

由 [[Qwen]] / QwenLM 组织公开维护。模型作者网络与当前 Qwen 团队、已离职校友需要按时间区分。
